# Thesis LLM setup component

Slurm and vLLM utilities for configuring local model profiles, launching services, and collecting runtime evidence. This component was stored inside the larger thesis repository and did not have independent Git history.

Start with `VLLM_MODELS_README.md` and `docs/` for environment requirements. Configure model endpoints and credentials locally before using `scripts/` or submitting `slurm/llm-stack.sbatch`.
